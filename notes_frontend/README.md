# Simple Notes - React Frontend

A single-page, frontend-only notes app built with React. Notes are stored in localStorage and never leave your browser.

## Quick start

- npm install
- npm start
- Open http://localhost:3000

## What you can do

- Add, edit (inline), and delete notes
- Confirm deletion before removing
- Search/filter by title and content
- Enjoy a clean, modern light UI with accessible controls
- Data persists with localStorage

## Tech

- React 18 + react-scripts
- No backend. No external UI frameworks.
- Styles in `src/App.css`

## Scripts

- npm start - run dev server
- npm test - run tests
- npm run build - production build
